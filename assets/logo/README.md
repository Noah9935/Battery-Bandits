# Logo Battery Bandits

Der Waschbär mit eckigen Konturen und Blitz. Transparenter Hintergrund, Größen von 16 bis 512 Pixel.

| Datei | Verwendung |
|-------|------------|
| `battery-bandits-logo.svg` und `battery-bandits-logo-<Größe>.png` | Hauptlogo, farbig (Weboberfläche, Favicon, README, Banner) |
| `battery-bandits-glyph.svg` | Einfarbiges Zeichen mit Batterie-Balken, für sehr kleine Flächen |
| `battery-bandits-glyph-dark-<Größe>.png` | Glyph in Dunkel, für helle Hintergründe |
| `battery-bandits-glyph-light-<Größe>.png` | Glyph in Hell, für dunkle Hintergründe |

Die Größen sind 16, 32, 64, 128, 256 und 512 Pixel (Breite gleich Höhe).
